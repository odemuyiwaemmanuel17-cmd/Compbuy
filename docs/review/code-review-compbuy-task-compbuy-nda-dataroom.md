## What Looks Good

- **Masking is structural, not advisory.** Putting the gate behind `Listing` properties
  means the failure mode for a new template is a visible `Members only`, not a leak. The
  audit that confirmed "no template reads a raw gated attribute" is mechanical.
- **Server-derived financials.** `annual_revenue`, `annual_profit`, and `revenue_band` are
  computed in `ListingCreate._values()`, so a client cannot post a listing whose public band
  contradicts its gated figures.
- **Every NDA transition is a conditional write** carrying the expected prior status, so a
  double-click or a seller/buyer race produces one winner and a `409` for the loser — proven
  by `test_approving_twice_is_a_conflict`.
- **Authority vs. state separation** after fix #8 is now explicit in the service
  (`get_for_seller` / `get_for_buyer` → 403; state machine → 409), which is what the first
  pass's "resource failures propagate honestly" policy asked for.
- **The enum-drift test** (`test_nda_status_and_offer_kind_enums_match_python`) compares the
  SQL enum declaration against the Python enum *in order* — the kind of guard that stops a
  migration and a model diverging silently.
- **Test-first defect discovery.** Both #2 and #3 were caught by existing assertions rather
  than by reading the code, which is evidence the pass-1 suite has real holding power.
